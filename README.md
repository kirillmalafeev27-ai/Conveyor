# CONVEYOR

Аркадная фабрика для практики немецкого языка от A1 до B2. Перед сменой игрок выбирает одну из 49 лексических и 51 грамматической темы, а затем отвечает в режиме узнавания или свободного воспроизведения. Заготовка едет по ленте через печь, пресс, вальцы, охлаждение и резак; правильный ответ даёт ровно одно вмешательство в её маршрут.

## Цель

Довести заготовку до приёмки в допуске уровня: выбрать ветку ленты и момент прохода под каждым станком так, чтобы температура, толщина, ширина и длина попали в цель.

## Управление

- `1–4` — выбрать форму ответа в режиме узнавания.
- `Enter` — отправить свободный немецкий ответ в режиме воспроизведения.
- `W` / `↑` / `Space` — сменить линию ленты.
- `A` / `←` — сдвиг назад, дольше под станком.
- `D` / `→` — сдвиг вперёд, быстрее из зоны.
- `Q` — применить сохранённый бонус.

## Локальный запуск

Нужен Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Форматы заданий

Формы упражнений и правила их составления лежат в [`lib/exercise-formats.ts`](lib/exercise-formats.ts) — том же наборе, что использует генератор See Escape:

- `gap` — немецкая фраза с ровно одним пропуском `___`; четыре варианта отличаются только проверяемым признаком.
- `word-order` — части предложения через ` / `; четыре варианта собраны из тех же частей и отличаются только порядком слов. Ответ, который тратит не все части или добавляет свои слова, отбраковывается на сервере.

`TOPIC_RULES` там же — построчный свод правил по каждой грамматической теме. Он уходит в запрос вместе с общими требованиями к качеству и закрывает главную беду генерации: задания, решаемые по второму, непроверяемому признаку.

## Вопросный поток

Клиент держит отдельную очередь для комбинации `уровень | лексика | грамматика` и начинает фоновое пополнение, когда очередь подходит к концу. Узнавание и воспроизведение намеренно делят один пул. Последние формулировки уходят в `exclude`, чтобы пакеты не повторялись. Если сервер, сеть или модель недоступны, игра без ожидания берёт встроенный разноуровневый резерв.

AITunnel вызывается только на сервере: для генерации пакетов и для смысловой проверки свободного ответа, если строгое локальное сравнение не сработало. Для локального production-режима скопируйте `.env.example` в `.env.local` и задайте `AITUNNEL_API_KEY`. `/api/questions/status` показывает только готовность серверной конфигурации, не раскрывая ключ, провайдера или модель.
